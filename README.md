# IntuitiveSpheres
A tool designed to help visually impaired individuals place objects in perspective (mimicking the visual field)

# Solution: How do I want to achieve the goal?

<img width="512" height="512" alt="image" src="https://github.com/user-attachments/assets/267024a2-5a93-41f8-85aa-e260da5d94eb" />

* Allow users to control the drawing environment entirely through voice commands
* Let users place the first vanishing point by speaking a number between 0 and 100
* 0 represents the left edge, 50 the center, and 100 the right edge of the horizon line
* Automatically calculate the second vanishing point using perspective geometry
* Let users place the horizon line by speaking a number between 0 and 100
* This determines the user's eye level
* 0 represents he top, 50 the middle, and 100 the bottom (0 = everything is below your eye level, 50 = can be above or below the eye level, 100 = everything is above your eye level)

<img width="529" height="579" alt="image" src="https://github.com/user-attachments/assets/5e23419a-d650-43bc-87c3-56eff968679a" />

* Every object follows the same perspective rule
* All objects have the same physical size in the virtual 3D environment
* Automatically adjusts the size based on the placement 
* Allow users to place objects using voice commands
* Objects follow the path defined by the vanishing point
* Each object is automatically assigned a number in the order it is placed
* Allows users to say the object number to retrieve all information about its position, shape, etc...
* Text-to-Speech is used to allow users to get feedback and confirm object placements
* Allow visually impaired individuals to create 3-D drawings. Fun and simple, without adding unnecessary complexities.
